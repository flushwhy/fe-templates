# {{.Name}}

A minimal Godot 4 2D starter with a runnable scene and keyboard movement.

## Run

1. Open this folder in Godot 4.
2. Press **F6** to run the main scene, or **F5** to run the project.
3. Move the square with the arrow keys.

## Export

Create desktop export presets in the Godot editor, commit `export_presets.cfg`, then run:

```sh
fe export --list-presets
fe export
```

Godot and the matching export templates must be installed separately.
